
- MCP server lives in src/lib/mcp (tools per file, OAuth via Lovable Cloud auth); the mcp edge function is generated by mcpPlugin — never hand-edit it. Why: one authoring surface, RLS runs as the connecting user.

- Keep former-item statuses in src/lib/itemStatus.ts and use sale_price only for sold/traded records. Why: lost, stolen, and given-away items have no sale proceeds but retain their history.
